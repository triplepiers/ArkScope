# 实现思路

> 复刻来源：[塞壬唱片](https://monster-siren.hypergryph.com/music#album)

- 整体逻辑：

    ```text
    真实标题
    => 生成 / 占位文本
    => 从左到右逐字符进入随机闪烁
    => 闪烁次数耗尽后替换为真实字符
    => 全部字符稳定
    ```


- 动画在 `content` 变化时重新开始：先取消上一轮未完成的 timeout、避免快速切换时多个动画同时写入同一段文本。

### 第一阶段：占位展开

清空显示文本、按原始标题字符从左到右追加占位符：
- 中文 / 日文字符 => "//"
- 英文 / 数字 => "/"
- 空格、-、/、' => 保留原字符

### 第二阶段：乱码闪烁

左 => 右 逐步解码文字，随机字符池会根据原字符类型选择：

- 英文 / 数字 => `a-z A-Z 0-9`
- 中文 / CJK => 注音符号、〇、天干等字符
- 日文假名 => 平假名 / 片假名


每个字符默认闪烁 `14` 次，帧间隔默认 `20ms`
