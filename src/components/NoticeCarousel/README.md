# NoticeCarousel

## Reveal 时间轴

组件挂载或调用 `reset()` 后，按以下顺序播放入场动画：

```text
t=0ms    标题灰色箭头块滑入；左侧竖条开始展开，塔体开始上移
t=300ms  公告轮播区域开始从右侧 reveal
t=400ms  英文标题 NOTICE 完成 blink 入场
t=600ms  中文标题“公告”完成 blink 入场
t=800ms  分页器与“更多情报”按钮完成 flash 入场；左侧“最新”装饰完成入场
```

## 轮播切换效果

点击卡片或左右分页按钮后：

- 当前卡片与相邻卡片沿轨道左右移动，位移使用原始公告轮播的 `sourceOffset` 计算；
- 当前卡片保持 `1` 倍显示，相邻卡片缩放至 `0.818` 倍，并带有约 `400ms` 的平滑位移与缩放过渡；
- 标题内容重新绑定后淡入淡出，切换动画约 `600ms`；
- 到达第一条或最后一条时，对应方向的分页按钮禁用。
